**Genspark에 먼저 붙여 넣기 ↓**
```
콘티 북 페이지에 넣을 완성 컷을 한 장씩 차례로 만들어 줘.
- 비율 16:9, 가로 1920px 이상

- 그림 안에 글자·숫자·로고 금지, 유명 애니 캐릭터와 닮으면 다시 만들 것

```

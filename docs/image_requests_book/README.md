## 1~7부 결과에서 배운 것
- 비교 그림(B)은 같은 대화에 'Same image. Change only' 한 줄로 요청하면 앞 그림·참고 그림을 따라가 설정 시트나 다른 인물이 나오기 쉬웠습니다. B07은 새 대화에서 전체 프롬프트로 만듭니다.
- 프롬프트에 없는 인물이 끼어들기도 했습니다. 끼어들면 'Only the characters described appear' 문장을 덧붙여 다시 만듭니다.

## 잘라 내기
완성 컷은 B03에서 받은 시트에서 **그 컷 하나만 잘라**(사각형 자르기) 첨부합니다. 잘라 낸 그림이 가로 300px보다 작으면 두 배로 키워 첨부합니다. 시트를 통째로 첨부하는 것은 B06 비교 한 장뿐입니다.

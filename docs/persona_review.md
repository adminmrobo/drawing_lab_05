# 페르소나 검사 — 구조 먼저 그리기 연구실 05 · 콘티 편 (v1.0, 2026-11-26)

자기 결과물 검사입니다. 9개 페이지(목차, 1~6부, 7부 연습장, 빈 콘티 양식)를 390px·1280px로 열어 실험 패널 25개와 연습장 미션 12개가 동작하는 것을 확인한 뒤, 실제 문장·실험·숫자만 근거로 평가했습니다. 본문 그림 27장은 아직 받지 않아 '그림 준비 중' 상태입니다.

## 0. 대상 요약
예시 콘티 「하루, 초파리를 찾아 옥상까지」(8컷)를 1~5부가 함께 쓰며, 뼈대(네 덩어리·세 줄·감정 곡선·썸네일) → 카메라(샷·눈높이 선·앵글·여백) → 컷 잇기(가상선·화살표·컷 길이·시선) → 포즈(중심축·무게중심·소품 무게·실루엣) → AI 컷(여덟 조각·기준 시트·강도·기준 컷) 순서로 익힙니다. 6부는 실패 8종 진단, 7부는 연습장 4곳과 인쇄용 빈 콘티 양식입니다.

## 5. 정리
입문자(A·E)는 순서와 실험은 쉽게 따라오지만 그림이 없고 모바일 글자가 작은 점에서 점수가 낮았고, 전문가(C·F)는 원리는 맞다고 보되 용어와 한 문장의 방향 표현을 지적했습니다. 1~4순위는 모두 바로 고칠 수 있어 이번 판에 반영했습니다. 남은 큰 과제는 그림 제작이며, 그림을 받으면 그림 설명(build/img_notes.py)과 '실제 결과'를 있는 그대로 채웁니다.
